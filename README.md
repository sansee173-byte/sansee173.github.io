# 🦔 Sonic Open Zone (2D)

Welcome to **Sonic Open Zone (2D)**! This is a browser-based, AI-assisted Sonic the Hedgehog fan game hosted directly on GitHub Pages. Run, jump, and dash through a recreated classic 2D environment.

👉 **[Play the game live here!](https://github.io)**

---

## 🎮 Game Controls

| Action | Key / Control |
| :--- | :--- |
| **Move Left / Right** | `←` / `→` Arrow Keys |
| **Look Up** | `↑` Arrow Key |
| **Crouch / Roll** | `↓` Arrow Key |
| **Jump** | `Spacebar` or `Z` |
| **Peel Out** | Hold `X` (Release to dash forward) |
| **Spin Dash** | Hold `↓` + Tap `Jump` (Release `↓` to dash) |
| **Drop Dash** | Press `↓` while in mid-air (Hold on landing) |

---

## 🛠️ How it Was Built

- **Engine:** Built using web technologies (HTML5, Canvas, and JavaScript).
- **Development:** Framework and physics logic generated with the assistance of AI.
- **Hosting:** Free static hosting via [GitHub Pages](https://github.com).
